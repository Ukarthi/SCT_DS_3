 # SCT_DS_3

## Task 3: Decision Tree Classifier

### Objective
Build a Decision Tree Classifier to predict whether a customer will purchase a product or service based on demographic and behavioral data.

### Tools Used
- Python
- Pandas
- Scikit-learn
- Matplotlib
- Google Colab

### Dataset
Bank Marketing Dataset (UCI Repository)

### Project Description
This project uses the Bank Marketing dataset to build a Decision Tree Classifier. The dataset was preprocessed by encoding categorical variables and splitting the data into training and testing sets. A Decision Tree model was trained and evaluated to predict customer subscription behavior.

### Steps Performed
- Loaded and explored the dataset
- Encoded categorical features
- Split data into training and testing sets
- Trained a Decision Tree Classifier
- Evaluated model accuracy
- Visualized the decision tree

### Results
- Model Accuracy: 87.40%
